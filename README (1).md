# Telugu Live TV Playlist (auto-refreshing)

A GitHub Actions workflow rebuilds an M3U playlist of live Telugu TV channels **every 30 minutes**. Each run fetches the source lists, tests every stream, and keeps only the links that currently work. Dead links drop out, and they come back automatically once the source fixes them.

## Playlist URLs

After you push this repo, use the raw links (replace `USER` and `REPO`):

| File | Contents |
|------|----------|
| `https://raw.githubusercontent.com/USER/REPO/main/telugu.m3u` | Working channels only (use this one) |
| `https://raw.githubusercontent.com/USER/REPO/main/telugu_all.m3u` | Every channel found, tested or not |
| `https://raw.githubusercontent.com/USER/REPO/main/status.json` | Last check time and list of dead links with reasons |

Paste the first URL into VLC, Kodi, TiviMate, OTT Navigator, IPTV Smarters, etc.

## Setup

1. Create a new GitHub repository and push these files.
2. In **Settings > Actions > General > Workflow permissions**, choose **Read and write permissions**.
3. Open the **Actions** tab, pick **Update Telugu playlist**, and click **Run workflow** for the first run.
4. After that it runs on its own every 30 minutes.

## Kodi add-on repository

The repo is also a Kodi add-on repository (same layout as repos like `tobalan.github.io`): `addons.xml`, `addons.xml.md5`, `zips/` and `repository.telugulive.zip` are generated by `scripts/build_kodi_repo.py` on every run. It ships one add-on, **Telugu Live**, which lists the channels from `telugu.m3u` grouped by category.

1. Turn on **GitHub Pages**: Settings > Pages > Source: *Deploy from a branch* > `main` / `(root)`.
2. After the first workflow run, your site is `https://USER.github.io/REPO/` (the workflow fills this URL in automatically).
3. In Kodi: Settings > System > Add-ons > allow **Unknown sources**.
4. Settings > File manager > Add source > `https://USER.github.io/REPO/` and name it `Telugu Live`.
5. Add-ons > Install from zip file > `Telugu Live` > `repository.telugulive.zip`.
6. Add-ons > Install from repository > Telugu Live Repository > Video add-ons > **Telugu Live** > Install.

The add-on's playlist URL can be changed in its settings. To ship a new add-on version, bump `version` in `kodi/plugin.video.telugulive/addon.xml` and push.

## Adding sources

Edit `sources.txt` and add one M3U URL per line. The default source is the community-maintained [iptv-org](https://github.com/iptv-org/iptv) Telugu list. Sources are merged, de-duplicated by stream URL, and tested together.

## How link checking works

- HTTP status must be below 400.
- HLS (`.m3u8`) links must return a real manifest, not an HTML error page or empty file.
- A safety guard keeps the previous playlist if a run finds zero working streams (for example during a network outage).

Run it locally with `python scripts/build_playlist.py` (Python 3.9+, no dependencies).

## Notes

- GitHub's scheduled runs can start a few minutes late, and GitHub disables scheduled workflows after 60 days of no repo activity on public repos. The bot's playlist commits count as activity, so it keeps itself alive as long as links change.
- Only use sources that carry free-to-air or officially public streams. You are responsible for the sources you add.
